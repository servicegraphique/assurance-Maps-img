# Référentiels de libellés (données publiques INSEE)

Ces fichiers servent uniquement à traduire des **codes** en **libellés lisibles**.
Ils ne contiennent aucune donnée d'entreprise.

| Fichier | Contenu | Source |
|---|---|---|
| `naf-codes.json` | Code NAF/APE → activité | Nomenclature NAF rév. 2, INSEE |
| `departements.json` | Code département → nom | Code officiel géographique, INSEE |
| `regions.json` | Code région → nom | Code officiel géographique, INSEE |
| `natures-juridiques.json` | Code catégorie juridique → forme sociale | INSEE |
| `tranches-effectifs.json` | Code tranche d'effectif → libellé | INSEE |

Copies issues du jeu de libellés publié par la DINUM dans le dépôt de l'API
Recherche d'entreprises : <https://github.com/annuaire-entreprises-data-gouv-fr/search-api/tree/main/app/labels>
